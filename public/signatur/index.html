TRIMOSA E-Mail-Signatur

Daten eintragen, Vorschau prüfen, kopieren, in Outlook einfügen. Logo und Farben sind fest hinterlegt.

Person

So kommt sie nach Outlook
  1. Oben „In Zwischenablage kopieren" drücken (kopiert die Signatur als formatiertes HTML).
  2. Outlook für Mac (neu): Outlook → Einstellungen → Signaturen → „+" → Namen vergeben → in das Textfeld klicken → ⌘V → Speichern. Dann unter „Standardsignaturen" dem Konto zuweisen.
  3. Outlook im Browser / Windows: Zahnrad → Konto → Signaturen → neue Signatur → einfügen → Speichern.
  4. iPhone-Outlook: Einstellungen → Signatur — dort ist nur Text möglich; „Nur Signatur öffnen" zeigt die Textfassung zum Kopieren.

Das Logo wird von trimosa.de geladen und erscheint beim Empfänger, sobald Bilder zugelassen sind — genau wie bei jeder Firmen-Signatur.
